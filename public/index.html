Quick command reference

Your shortcuts.

Type a command in the bot chat to get where you need to go. Admin controls remain restricted to authorized administrators.

/startOpen the main menu or follow a referral link
/helpRead the quick guide
/referralOpen your invite link and stats
/rulesRead tournament and fair-play rules
/prizesWallet and payout information
/requestRequest approval for a group
/adminOpen the admin control panel
/addadminOwner-only: add an admin by user ID
/pingCheck that the bot is responding
Community management

Open by choice. Restricted by design.

Use the access mode that fits your community. The owner and approved administrators can manage access from the inline control panel.

Group approval flow

When the bot is in restricted mode, a group can request access without an admin needing to manually copy chat IDs around.

01
Request from the groupRun /request in the group to get a private access link.
02
Submit the requestOpen the bot privately and confirm the group request.
03
Review in the control panelAdmins can approve or reject requests, and approved chats can be removed later.
